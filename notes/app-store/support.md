# Tanzakoo サポート / Support

Tanzakooは、アイデアをカードにし、ボードで整理するMacアプリです。Apple Silicon搭載Mac、macOS 26以降に対応します。

## お問い合わせ

[huruikagi@gmail.com](mailto:huruikagi@gmail.com) へ、アプリのバージョン、macOSのバージョン、行った操作、表示されたエラーをお知らせください。画像を添付する場合は、カード本文やファイルパスなどの個人情報を確認してください。認証コード・APIキー・パスワードは送らないでください。

## よくある質問

**AIのアカウントは必要ですか？**

ボード編集、プロジェクトメモリ、Markdownエクスポートはアカウントなしで使えます。通常のAI接続には、ご自身のCodex対応ChatGPTアカウントが必要です。外部サービスのプランと上限が適用されます。

**AIへ何を送りますか？**

送信の同意後、会話に加えてボード、メモリ、登録資料のパスや必要な抜粋などを送ります。機密資料を登録する前に、[プライバシーポリシー](privacy-ja.md)を確認してください。

**AIの変更提案はすぐ反映されますか？**

候補カードの作成と、既存カードへの変更提案は異なります。変更提案は内容を確認し、「適用する」を押すまで保存済みの内容を変更しません。

**PDFを資料にできますか？**

現在はMarkdownやソースコードなどのUTF-8テキストに対応します。PDF・画像は対象外です。資料は読み取り専用です。

**接続できない、または429と表示されます。**

接続状態と表示された上限を確認し、時間を置いて再試行してください。審査用コードが期限切れ・利用上限の場合は窓口へご連絡ください。審査用コードはアプリを終了すると再入力が必要です。ローカルのボードはそのまま使えます。

**決まった内容を持ち出すには？**

カードを「決めたこと」に移し、「エクスポート」から保存先を選びます。確定したカードとメモリをMarkdownへ書き出します。保留中の変更案やチャット履歴は含みません。

## English support

Tanzakoo helps you explore ideas with cards and a board. Requires an Apple Silicon Mac running macOS 26 or later.

Contact [huruikagi@gmail.com](mailto:huruikagi@gmail.com) with your app version, macOS version, steps, and error message. Remove private card text and file paths from screenshots. Never send access codes, API keys, or passwords.

**Do I need an AI account?** Manual board editing, project memory, and Markdown export work without an account. Regular AI access requires your own ChatGPT account with Codex access and is subject to that service's plan and limits.

**What is sent to AI?** With your consent, conversation context, the board, project memory, registered reference paths, and relevant excerpts are sent. Read the [privacy policy](privacy-en.md) before registering confidential material.

**Are AI changes applied immediately?** AI can create candidate cards. Proposed changes to existing cards remain pending until you review them and select Apply.

**Can I reference PDFs?** The current version supports UTF-8 text, including Markdown and source code. PDFs and images are unsupported. References are read-only.

**What if connection fails or I see 429?** Check the connection status and usage limits, then retry later. Contact support if a review code expires or runs out. Review codes must be entered again after quitting. Your local board remains available.

**How do I export?** Move cards to Decided, choose Export, and select a destination. Saved decisions and memory are exported as Markdown. Pending changes and chat history are excluded.
