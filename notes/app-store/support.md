# Tanzakoo サポート / Support

更新日 / Updated: 2026-10-01

Tanzakooは、アイデアをカードにし、ボードで整理するアプリです。Mac版はApple Silicon搭載Mac、macOS 26以降が対象です。Mac App Store版・Microsoft Store版の公開を準備しています。

## お問い合わせ

通常のお問い合わせは **GitHub Issue Forms** で受け付けます。日本語・英語どちらでも書けます。

- [不具合を報告する](https://github.com/Huruikagi/tanzakoo/issues/new?template=bug-report.yml)

投稿にはGitHubアカウントが必要です。**投稿内容・添付画像・返信は公開されます。** メールアドレス、認証コード、APIキー、パスワード、私的なカードや参照資料、未加工のログを投稿しないでください。画像やエラーの抜粋からも、本文・ファイルパス・認証情報を伏せてください。

## よくある質問

**AIのアカウントは必要ですか？**

ボード編集、プロジェクトメモリ、Markdownエクスポートはアカウントなしで使えます。通常のAI接続には、「ChatGPTで続ける」で接続できるご自身のChatGPTプランと利用許可が必要です。外部サービスのプランと上限が適用されます。

**AIへ何を送りますか？**

送信の同意後、会話に加えてボード、メモリ、登録資料のパスや必要な抜粋などを送ります。機密資料を登録する前に、[プライバシーポリシー](privacy-ja.md)を確認してください。

**AIの変更提案はすぐ反映されますか？**

候補カードの作成と、既存カードへの変更提案は異なります。変更提案は内容を確認し、「適用する」を押すまで保存済みの内容を変更しません。

**PDFを資料にできますか？**

現在はMarkdownやソースコードなどのUTF-8テキストに対応します。PDF・画像は対象外です。資料は読み取り専用です。

**接続できない、または429と表示されます。**

接続状態と表示された上限を確認し、時間を置いて再試行してください。審査用コードが期限切れ・利用上限の場合は窓口へご連絡ください。審査用コードはアプリを終了すると再入力が必要です。ローカルのボードはそのまま使えます。

**決まった内容を持ち出すには？**

カードを「決めたこと」に移し、「エクスポート」から保存先を選びます。確定したカードとメモリをMarkdownへ書き出します。保留中の変更案やチャット履歴は含みません。

## English support

Tanzakoo helps you explore ideas with cards and a board. The Mac version requires Apple Silicon and macOS 26 or later. Mac App Store and Microsoft Store releases are in preparation.

Use **GitHub Issue Forms** for general support. Japanese and English are welcome.

- [Report a bug](https://github.com/Huruikagi/tanzakoo/issues/new?template=bug-report.yml)
- [Ask a question or suggest an improvement](https://github.com/Huruikagi/tanzakoo/issues/new?template=question-request.yml)
- [Browse existing reports and answers](https://github.com/Huruikagi/tanzakoo/issues)

A GitHub account is required to post. **Posts, attachments, and replies are public.** Do not post email addresses, access codes, API keys, passwords, private cards or reference materials, or unredacted logs. Remove private content, file paths, and credentials from images and error excerpts.

### Private contact

For personal data, deletion requests, review access, or security reports, email [huruikagi@gmail.com](mailto:huruikagi@gmail.com) instead of opening a public issue. Email is also available if you do not have a GitHub account. Never email access codes, API keys, or passwords.

### Frequently asked questions

**Do I need an AI account?** Manual board editing, project memory, and Markdown export work without an account. Regular AI access requires your own eligible ChatGPT plan and permission through Continue with ChatGPT and is subject to that service's plan and limits.

**What is sent to AI?** With your consent, conversation context, the board, project memory, registered reference paths, and relevant excerpts are sent. Read the [privacy policy](privacy-en.md) before registering confidential material.

**Are AI changes applied immediately?** AI can create candidate cards. Proposed changes to existing cards remain pending until you review them and select Apply.

**Can I reference PDFs?** The current version supports UTF-8 text, including Markdown and source code. PDFs and images are unsupported. References are read-only.

**What if connection fails or I see 429?** Check the connection status and usage limits, then retry later. Contact support if a review code expires or runs out. Review codes must be entered again after quitting. Your local board remains available.

**How do I export?** Move cards to Decided, choose Export, and select a destination. Saved decisions and memory are exported as Markdown. Pending changes and chat history are excluded.
