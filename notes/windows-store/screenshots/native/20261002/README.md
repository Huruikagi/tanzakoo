## 撮影元と確認

- 2026-10-01の提出候補 `Tanzakoo-1.0.0.0-x64.msix` の展開済みpayloadから起動。実行ファイルのSHA-256がパッケージ作成記録の値と一致した。MSIXとしてインストールした状態の試験ではない。
- `TANZAKOO_DATA_DIR` で撮影用領域を分け、サンプルの2プロジェクト・各7カードを実際のUI操作で作成した。通常のプロジェクトや認証情報を使っていない。
- [撮影スクリプト](../../../../../scripts/capture-windows-store.ps1) の `-Ready -Width 2160 -Height 1350` を使用。4列が見渡せるよう詳細ペインの幅を調整した。
- 全6枚を目視し、文字・言語・画面欠け・エラー・個人情報を確認した。PNGのサイズ・形式とSHA-256も照合した。
- [selection.json](selection.json) は選定と目視確認の記録。`records/` 内は撮影時の記録をそのまま保存し、その後の目視確認結果で書き換えていない。

**設定内の公開リンクを含む差し替えMSIXとの画面一致は未確認。** 最終提出ビルドで確認してから採用する。撮影記録のチェックアウトIDは実行ファイルのビルド元を証明しない。ストアへの自動アップロードは行っていない。
